# Documentación

Estructura exigida por la guía de despliegue de DATIC (apartado 4.2). Manuales en PDF; scripts en texto.

| Subcarpeta | Contenido exigido | Estado |
|---|---|---|
| `Manuales/` | Instalación, operación, mantenimiento y copias de seguridad | Completos (MAN-01 v1.3, MAN-02 v1.1, MAN-03 y MAN-04 v1.0) |
| `Modelo de Datos/` | Modelo relacional, diccionario de datos y script de creación | Completo (v1.0) |
| `Pruebas/` | Funcionalidad e integración, rendimiento, seguridad, habeas data y estrés | Completo: PRU-00 a PRU-07 (simulados; recomendación condicionada en PRU-07) |
| `Arquitectura/` | Diagrama con flujos frontend → backend → base de datos y direcciones IP | Completo (v1.1, IP simuladas) |
